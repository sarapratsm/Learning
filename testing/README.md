# Testing — Guías

Cómo escribir tests con criterio: qué herramienta usar en cada capa, cómo estructurarlos y qué distingue una suite fiable de una que solo pinta verde.

Las tres metodologías que usan pruebas y especificaciones para guiar el desarrollo: el ciclo rojo-verde-refactor, los escenarios Gherkin con Reqnroll y la especificación como contrato.
