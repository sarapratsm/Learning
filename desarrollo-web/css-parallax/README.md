# CSS Parallax — Guía de tecnologías

Cómo conseguir con CSS el efecto de profundidad en el que el fondo se mueve más despacio que el primer plano al hacer scroll. Empieza por el origen del término y su historia (de la astronomía y la cámara multiplano del cine a los videojuegos y la web) y recorre las tres técnicas de CSS, de la más simple a la más moderna, con su accesibilidad y rendimiento.

Está pensada para perfiles backend que programan a diario pero no han trabajado con efectos visuales en el navegador. No presupone experiencia previa: cada técnica se explica con su código y sus límites.
