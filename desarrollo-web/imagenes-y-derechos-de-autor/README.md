# Imágenes y derechos de autor — Guía

Cómo poner fotos en una web sin problemas de derechos de autor: qué protege el copyright, qué significan las licencias (Creative Commons, dominio público, licencias propias de los bancos), de dónde conseguir imágenes gratuitas y qué hábitos seguir al publicarlas.

Está pensada para perfiles de desarrollo que montan o mantienen webs (una tienda online, un blog, la web de una pyme) y tienen que decidir de dónde sacar las imágenes. No requiere conocimientos legales.

Las fichas son orientativas y no constituyen asesoramiento legal. Las licencias cambian con el tiempo: lo vinculante es lo que diga la página del banco o de la licencia el día de la descarga.
