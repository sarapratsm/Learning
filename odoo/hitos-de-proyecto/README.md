# Hitos de proyecto en Odoo — Guía de tecnología

Qué es un hito en el módulo de Proyecto de Odoo, cómo se activa, cómo se enlazan las tareas a él, qué reglas siguen las subtareas y cómo se ve el avance; y, como segunda pieza, cómo un hito alcanzado puede convertirse en el momento de facturación de un pedido de venta. Pensada para quien ya conoce los módulos de Proyecto y Ventas de Odoo desde el uso, o desde otro sistema de gestión de proyectos, pero no ha trabajado con hitos.
